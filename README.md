## 🌐 Abstract

This project integrates **Blockchain**, **IoT**, **AI**, and **VANETs** to create a secure, tamper-proof, and intelligent system that prevents fuel pilferage in generator sets (gensets). Using smart sensors and distributed ledgers, every fuel transaction is tracked and validated in real-time, ensuring transparency, accountability, and efficiency in the fuel supply chain.

---

## 📌 Key Features

- 🛡️ **Blockchain Ledger** for tamper-proof fuel transaction records  
- 📶 **Wireless Sensor Network (WSN)** for real-time fuel level detection  
- 🚗 **VANET Integration** for fleet tracking and geo-verification  
- 🤖 **AI Models** to detect anomalous fuel usage or theft  
- 🔐 **RFID Verification** of personnel and vehicles  
- 📊 Live dashboard for monitoring and alerts
